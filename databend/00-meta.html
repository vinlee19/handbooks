6. 术语表

术语 含义 备注
FUSE engine Databend 默认表引擎，三层文件结构 Snapshot → Segment → Block 与 Linux FUSE 文件系统无关
Snapshot 表的某个版本元数据，包含 segment 列表、统计信息、cluster key 不可变；prev_snapshot_id 形成链表实现 Time Travel
Segment 一组 block 的容器，自带 segment 级聚合统计
Block 实际数据块，对应对象存储一个文件（默认 Parquet） BlockMeta 上挂 bloom/inverted/vector/spatial 等索引 location
OpenDAL 对所有对象存储的统一抽象层（S3/GCS/Azure/OSS/HDFS/FS/...） Operator 上叠加 Retry/Timeout/ConcurrentLimit/Logging/Metrics 等 Layer
Cascades / DPHyp 优化器框架：Cascades 用于规则/分组 memo 探索；DPHyp 用于多表 join 的动态规划枚举 两者并存且分工不同
Pipeline / Processor / Port push-based 执行模型：DAG 上的 Processor 节点通过 Port 推送 DataBlock，Event 状态机驱动调度 PipelineExecutor 在 worker 间 work-stealing
DataBlock 列存内存批，由若干 Column + 元数据组成，是 pipeline 中流转的基本单位
BindContext Binder 输出的上下文，记录列绑定、可见列集合、CTE/外层引用
SExpr Single-Expression Tree，逻辑计划的不可变表达 缓存关系属性（基数、输出列、分区）
PhysicalPlan 物理算子的 enum 派发；每个变体自带 build_pipeline 实现 没有「单独的 PhysicalPlan trait」，而是 enum
MetaStore meta 客户端抽象，可包内嵌或走 gRPC；本仓库代码硬性禁用 embedded 模式 src/meta/store/
META_CHANGE_LOG meta 类型 protobuf 版本追加日志；只允许尾部追加，前部清理 src/meta/proto-conv/src/util.rs
EE / OSS 企业版 / 开源版二进制；通过不同 license-manager 入口区分 ee_main.rs vs oss_main.rs
