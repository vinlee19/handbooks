coding-agent：把三层地基组装成产品

58,703 行，仓库里最大的包。它不实现任何"智能"——那在 agent 包里；它做的是装配：把 SettingsManager、ModelRuntime、ResourceLoader 三件套接进 createAgentSession()，用 7 个内置工具和动态拼装的 system prompt 喂给 Agent 循环，再把循环的事件翻译成 TUI 渲染与 JSONL 落盘。

2AgentSession：编排核心

core/agent-session.ts（3,342 行）是事件与动作的枢纽。它持有 Agent（03 篇的循环薄壳）和 SessionManager（05 篇的 JSONL 树），把两者缝在一起：循环的每个事件既广播给 UI/扩展，又被写成会话 Entry。它的 prompt() 方法是所有输入的总入口，前置管线值得整段读：

每个工具是 ToolDefinition（TypeBox 参数 schema + execute + 可选的 renderCall/renderResult UI 渲染器），经 wrapToolDefinition 降配成 agent 包的 AgentTool 再交给循环。权限上内核不设防——拦截点在扩展的 tool_call 事件（06 篇），官方示例 permission-gate.ts 就是这样实现确认门的。0.84.2 起在 PI_EXPERIMENTAL=1 下，这四个默认工具的 schema 会启用 strict 约束采样。
