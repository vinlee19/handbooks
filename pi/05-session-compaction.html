会话持久化与上下文压缩

会话文件就是日志：首行 header，之后每行一个带 id/parentId 的 Entry，只追加、不改写。分支是移动指针，压缩是追加一条 Entry。本篇拆 JSONL v3 格式、branch/resume 语义，以及 compaction 的两个算法问题：何时压（阈值公式）与在哪切（切点搜索）。

1磁盘上的会话：JSONL v3

每个会话是 ~/.pi/agent/sessions/--<cwd 转义>--/session-<id>.jsonl 下的一个文件（cwd 里的 / 转成 -，因此会话按项目天然分目录）。文件第一行是 header，之后每行一个 Entry。Entry 类型的联合定义如下：

2append-only 树与 branch

分支的实现只有一行赋值——这是"事件溯源"式存储的红利：

packages/coding-agent/src/core/session-manager.tsL1354-1374
/**
 * Start a new branch from an earlier entry.
 * Moves the leaf pointer to the specified entry. The next appendXXX() call
 * will create a child of that entry, forming a new branch. Existing entries
 * are not modified or deleted.
 */
branch(branchFromId: string): void {
  if (!this.byId.has(branchFromId)) {
    throw new Error(`Entry ${branchFromId} not found`);
  }
  this.leafId = branchFromId;        // 就这。历史原封不动。
}

resetLeaf(): void {
  this.leafId = null;                // 下一跳直接成为新根（重写第一条消息用）
}

buildSessionContext() 负责把树折叠回线性消息数组：从 leaf 沿 parentId 回溯到根，遇到 compaction Entry 时，把 firstKeptEntryId 之前的消息替换为摘要文本、之后的原文保留；遇到 branch_summary 则注入一条"user 消息"说明前情。header 之外的全部信息都在这一条回溯路径上。

4在哪切：findCutPoint

摘要不能覆盖整个上下文——最近的若干 token 必须保留原文（模型需要确切的代码与错误信息）。于是问题变成：从后往前数 keepRecentTokens 个 token，然后找一个"合法切割点"。合法性的定义很有意思：

export function findCutPoint(entries, startIndex, endIndex, keepRecentTokens): CutPointResult {
  const cutPoints = findValidCutPoints(entries, startIndex, endIndex);
  if (cutPoints.length === 0) {
    return { firstKeptEntryIndex: startIndex, turnStartIndex: -1, isSplitTurn: false };
  }

  // Walk backwards from newest, accumulating estimated message sizes
  let accumulatedTokens = 0;
  let cutIndex = cutPoints[0];

  for (let i = endIndex - 1; i >= startIndex; i--) {
    const messageTokens = sessionEntryToContextMessages(entries[i])
      .reduce((sum, m) => sum + estimateTokens(m), 0);
    if (messageTokens === 0) continue;
    accumulatedTokens += messageTokens;

    if (accumulatedTokens >= keepRecentTokens) {
      // Find the closest valid cut point at or after this entry
      for (let c = 0; c < cutPoints.length; c++) {
        if (cutPoints[c] >= i) { cutIndex = cutPoints[c]; break; }
      }
      break;
    }
  }
  ...  // 随后再向前吞并相邻的"不可见元数据 Entry"，并判定 split-turn
}
