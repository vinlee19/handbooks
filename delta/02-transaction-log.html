Transaction Log：七个 action 定义一张表

_delta_log/00000N.json 里每行一个 action（JSON）。七类 action 组合起来就是 Delta 表在某一刻的完整描述：文件账本（add/remove）、表定义（meta/protocol）、流幂等（setTransaction）、审计（commitInfo）与扩展位（domainMetadata）。

02原子性与 LogStore

对象存储上「文件写完整即完整可见」，所以 Delta 的原子提交 = 把整个 JSON 写完再让它出现。HDFS 有原子 rename 天然支持；S3 没有，由 LogStore 抽象补齐：S3SingleDriverLogStore 配合 DynamoDB 条件写（putIfAbsent）实现「同版本号只有一个提交者赢」。

这个抽象也是社区争议最多的地方（早期 Azure/S3 行为差异），读源码时注意 LogStoreProvider 按 scheme 分发的逻辑与 delta.logStore.* 配置族。
