每个 action 类定义在 actions/ 包（AddFile.scala、RemoveFile.scala、Metadata.scala…），通过 JsonUtils 与 Jackson 映射，Action 伴生对象负责反序列化分发。

02可见性与原子性

对象存储上「文件一旦写完整即完整可见」，因此 Delta 的原子提交 = 写完整个 JSON 再让它出现。不支持原子重命名的存储（如 S3）靠 LogStore 的实现（S3SingleDriverLogStore + DynamoDB 锁）补齐语义——这就是 LogStore 抽象存在的原因。

dataChange:false 的 add/remove（如 Optimize 产物）不改变逻辑数据，只改变物理布局——增量feed的消费者据此过滤。
