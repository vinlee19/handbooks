§0.1一句话理解 DuckLake

DuckLake 是 DuckDB 官方推出的开源 Lakehouse 格式，它的设计哲学只有一句话：

🎯 核心设计
把 Lakehouse 的"元数据"从一堆 JSON/manifest 文件里搬回数据库——元数据存进一个支持 ACID 的 SQL 目录数据库（DuckDB / SQLite / Postgres / Quack 远程服务），数据存为云上朴素的 Parquet 文件。用一张 ducklake_snapshot 表替代 Iceberg 的 manifest 链，用事务替代文件重命名协议，从而获得没有分布式协调开销的完整 ACID、原生 Time Travel、秒级 DDL。

对 DuckDB 而言，DuckLake 是一个 ATTACH 型存储扩展（Storage Extension）：一条 ATTACH 'ducklake:meta.ducklake' (DATA_PATH 's3://bucket/lake')，DuckDB 里就多出一个完整的 Lakehouse 数据库，增删改查、事务、快照回溯全部开箱即用。
