§8.6配置与选项体系

ducklake_set_option / options / settings

三个函数覆盖三级配置的写与读（CH 02 §2.7）：ducklake_set_option(c, 'k','v') 全局；ducklake_set_option(c,'schema','k','v') schema 级；再带表名则 table 级。读取用 ducklake_options(c[, schema[, table]])，全局 SET 用 ducklake_settings(c)（ducklake_set_option.cpp:235 / ducklake_options.cpp:175 / ducklake_settings.cpp:49）。

ducklake_set_commit_message

为事务的下一个提交定制 ducklake_snapshot_changes.commit_message 与 author（ducklake_set_commit_message.cpp:56）——审计友好：每次提交在快照表里可读"谁、为什么"。

§8.7murmur3 与内部函数

  • murmur3_32(col)（ducklake_murmur3.cpp:102）：与 Iceberg 规范逐字节一致的 murmur3 哈希，bucket(n, col) 分区的数学基础；NULL 处理近期修复为 FlatVector::SetNull（见 HEAD 提交 #1035）。
  • ducklake_scan（:113-115）：为 scan 绑定信息反序列化注册的内部表函数——并行扫描 worker 需要 rebuild DuckLakeFunctionInfo。
  • ducklake_commit（ducklake_commit.cpp:70-76）：服务端提交入口（CH 06 §6.6），返回一行三元组 (committed_snapshot_id, committed_schema_version, had_flushes)。
