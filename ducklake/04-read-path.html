来源物理形态适用场景内存结构

deletion vector…-delete.puffin（roaring bitmap blob）ducklake_write_deletion_vectors=trueroaring bitmap → 解码为位图
inlined deletes元数据库内联表行数据被内联的小表直接 SQL 过滤

§4.7动态过滤与统计

Top-N 动态过滤（Dynamic Filter）

ORDER BY … LIMIT N 执行中，DuckDB 把"当前第 N 名的排序键值"回灌给扫描。DuckLake 把它转成 partial_max < 阈值 谓词对文件列表动态重裁剪——文件列表是惰性的（GetFiles 首次调用才拉取），天然支持二次裁剪。

Join 谓词下推

DuckLakeUtil::ExtractDynamicFilter 一类工具从过滤条件提取可下推表达式，经 filter_info 传入 GetFilesForTable 的 SQL——min/max 裁剪用的是"过滤后的"谓词，而不只是用户写下的 WHERE。
