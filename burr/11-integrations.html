11 · 集成生态：外接世界的全部接口

源码：burr/integrations/。Burr 不试图包裹一切——集成只做三类事：把外部组件变成 Action、把状态类型变成 pydantic、把追踪数据桥接到 OTel/Langfuse。

11.2 Hamilton 双向集成（血缘最近的伙伴）

Burr ← Hamilton：DAG 变动作

Hamilton(Action)（hamilton.py:106）把一个 Hamilton Driver 包成单个动作：

hamilton_action = (
  Hamilton(driver)
  .with_inputs(                    # 外部 run_kwargs 进 DAG
    from_value(query="..."))
  .with_outputs({                  # DAG 结果出向 State
    "llm_output": update_state("response"),
    "chunks": append_state("history")}))

Hamilton 负责一次 DAG 内的计算编排，Burr 负责跨 DAG 的状态机推进与观测。

Hamilton 侧的 Burr 追踪

反向地，Hamilton 官方包（sf-hamilton）提供 tracker 把 DAG 运行写入 Burr UI——所以 UI 里你能看到「一个 action 里面还有一张 DAG 图」的两层结构。这解释了：

  • 为何 Burr 的动作有 get_source() 供 UI 展示；
  • 为何追踪事件模型里 span 可以任意嵌套（06 篇）；
  • 历史渊源：Burr 出生就是 Hamilton 的「状态外壳」。

11.4 pydantic 类型化状态（guardrails 模式）

两个装饰器 + 一个类型系统

  • @action.pydantic(reads, writes, state_input_type, state_output_type)（action.py:1852 转发到 integrations/pydantic.py:192）——动作签名里的 state 参数变成 pydantic 模型，引擎自动做双向转换；
  • PydanticTypingSystem（:393）实现 02 篇的 TypingSystem：让整个应用以模型为外观；
  • subset_model(state, keys) / merge_to_state(model, state)（:171 附近）——把「部分模型」安全地写回状态，实现字段级 guardrails。

何时值得用

  • 状态结构复杂、需要字段校验（LLM 结构化输出直接进模型）；
  • 想要「改一个字段名，全链路 IDE 报错」的重构体验；
  • 配合 instructor 等结构化输出库使用。
代价：每步有模型构造/校验开销；且 data 物化是 cached_property——跨步不会缓存，注意热路径。

11.5 serde 插件与运行环境集成速览

serde 插件机制

插件就是「在 import 时向 02 篇的两级注册表注册函数」的模块。以 pandas 为例：serialize_pydantic 风格的函数把 DataFrame 变成 {"__burr_serde__": "pandas.DataFrame", "value": records}，反序列化时经 StringDispatch 还原。pickle 插件出于安全考虑要求逐类型显式注册。

streamlit.py（旧 UI）

React UI 出现前的探索工具：`render_state_machine` 用 graphviz 在 Streamlit 里画图、读 log.jsonl 回放。现属「轻量替代品」，代码仍是学习 log.jsonl 格式的好材料。

notebook.py

%load_ext burr.integrations.notebook 后获得 notebook magic 与 launch_ui()：在 Jupyter/Colab 里以子进程拉起追踪服务并自动开浏览器端口转发（Colab 场景）。Graph/Application 的 _repr_mimebundle_ 让 notebook 内联渲染 graphviz 图。

本篇要点：① 集成只有三类姿势：组件→Action、状态→类型、追踪→桥；② Hamilton 是双向深度集成（DAG in action、tracker in UI）；③ OTel 桥是双向的：出向镜像 + 入向回填，Langfuse 白嫖同款；④ 一切可选依赖都懒加载，内核零感知；⑤ LLM SDK 不被包装——Burr 刻意让你直接写业务代码。
