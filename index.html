如何新增一本手册

唯一方法：在仓库根目录的 manifest.conf 中新增一行 name|图标|标题|描述|主题色|源HTML目录，然后运行 ./publish.sh —— 脚本会自动同步该目录的 HTML、重建根导航页、提交并推送到 GitHub Pages。
