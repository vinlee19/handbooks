05 · 向量索引：从 K-means 到 HNSW 图遍历

Lance 的向量索引体系（rust/lance-index/src/vector/，含 ivf/pq/sq/bq/hnsw/flat/graph/v3 子模块）是"ANN 加速器"。本章从数学原理到源码实现全链路解析：训练、量化、建图、三级复合索引、查询执行计划。

1. 索引家族全景

索引原理召回/速度定位源码位置
FLAT暴力全扫（SIMD 距离）100% 召回基线；小数据/精确检索vector/flat.rs
IVF_FLATK-means 分区 + 分区内暴力低内存；中等规模vector/ivf/
IVF_PQ分区 + 乘积量化编码十亿级向量主力；有损vector/pq/
IVF_SQ分区 + 标量量化(f32→i8/f16)高召回、速度居中vector/sq/
IVF_HNSW(×PQ/SQ)分区 + 图索引 + 量化（v3 复合）最高 QPS 的组合vector/v3/
HNSW 单体多层邻近图高召回、构建较慢vector/hnsw/
BQ（二值量化）符号位压缩 + 汉明距离内存 32×↓，配合 rerankvector/bq.rs
RaBitQ 类理论有界随机量化实验/企业版延伸vector/bq/

所有索引共享统一抽象：Index trait（加载/查询/statis）+ VectorIndex（ANN 专用）+ 存储层 IvfQuantizationStorage<Q>（v3：分区存储 + 量化码）。

2. IVF：倒排文件分区

IVF 的本质是把向量空间切成 num_partitions 个 Voronoi 胞腔，查询只探最近的 nprobes 个分区，扫描量从 N 降到 N×nprobes/K。

图 5-1 · IVF 构建四步。Shuffler（ivf/shuffler.rs）用外部排序避免 OOM。

3. PQ 乘积量化：把 768 维压成 96 字节

PQ（vector/pq/builder.rs，ProductQuantizer）把向量切成 M = num_sub_vectors 段，每段独立 K-means 出 2^num_bits（通常 256）个质心。向量→每段一个码字 → 存 M 字节（768 维 f32 的 96×压缩）。

图 5-2 · PQ 两阶段。ADC 的名字来自"不对称"：查询用原向量、库中向量用量化码。

3.1 SQ / BQ 一览

量化器变换距离计算适用
SQ（ScalarQuantizer）每维 min-max/f16 归一到 i8（4× 压缩）或 f16（2×）整数 SIMD 或 f16 SIMD，近似 L2/内积追求高召回（PQ 有码本偏置时 SQ 更稳）
BQ（BinaryQuantizer）取符号位 → bit 串（32× 压缩）popcount 汉明距离（07 篇 hamming.rs）超高维、可接受 rerank 的场景

4. HNSW：多层跳表式邻近图（源码级）

HNSW（vector/hnsw/builder.rs + online.rs）默认参数：max_level=7、M=20、ef_construction=150。它把"跳表"思想搬到度量空间：上层稀疏长边加速导航，第 0 层稠密短边保证精度。

图 5-3 · HNSW。构建采用 online.rs 的流式插入（InsertBuilder 逐向量 add + select_neighbors_heuristic 启发式裁边），适合增量场景。

6. ANN 查询在执行计划中的物理形态

// scanner.rs 中 ANN 查询生成的计划（简化）
StreamingTableFunc          // 输出流
└─ TakeExec                 // 用 ANN 结果 row_addr 取回列数据
   └─ ANNIvfPartitionExec   // 每个 nprobe 分区一个并行子计划
      ├─ ANNIvfSubIndexExec // 分区内 HNSW/PQ 检索（可再切 subindex 并行）
      └─ KNNVectorDistanceExec // 残余部分(未覆盖 fragment)的暴力 SIMD 距离
         └─ MultivectorScoringExec // 多向量(MaxSim)时打分

选型决策树：数据 < 100 万且要精确 → FLAT。1~1000 万、内存宽裕 → IVF_SQ 或 IVF_HNSW_SQ。亿级 → IVF_HNSW_PQ + refine_factor≥5。超低延迟在线服务 → HNSW（未分区）或 v3 复合 + 提高内存缓存。若做过滤检索（filter+ANN）→ 关注 search_acorn 与 prefilter 融合。
