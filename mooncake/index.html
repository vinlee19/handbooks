Mooncake 源码深度学习手册

Mooncake 是月之暗面（Moonshot AI）Kimi 大模型服务的底层平台，核心是 KVCache-centric 分离式架构：将 LLM 推理的 Prefill 与 Decode 集群分离（PD 分离），并把 GPU 集群中空闲的 CPU / DRAM / SSD 组织成分布式的 KVCache 池。本手册基于对全部源码的逐模块深度分析，用 11 页图文带你从零理解它的原理、架构与底层实现。基线版本：main @ 53e41174（debug-learning 分支）。

🔍如何对照源码阅读

手册中所有结论均给出 文件 : 函数/类 定位。推荐三个对照动作：

  • 定位源码：核心目录是 mooncake-transfer-engine/src（引擎与传输）、mooncake-store/src（Master 与 Client）、mooncake-store/src/ha（高可用）。
  • 跑起来：最小集群只需三个进程 —— mooncake-master（元数据服务）、etcd（或 mooncake_http_metadata_server 替代）、以及挂载了 segment 的客户端。docker/ 目录有一键镜像。
  • 观察行为：Master 暴露 Prometheus 指标（默认 :9003，monitoring/ 有 Grafana 面板）；环境变量（MC_*，见 mooncake-transfer-engine/src/config.cpp 的 globalConfig()）可调整 slice 大小、QP 深度、日志级别等，是调试的钥匙。
版本说明：本手册基于 main @ 53e41174。Mooncake 迭代很快（TENT 新一代引擎正在并行演进），若行号有漂移，请以函数/类名为锚点检索。
