DuckDB 是进程内嵌的列式 OLAP 数据库：SQLite 的部署形态 + 向量化执行 + 列存压缩。没有服务端、没有网络协议，整台引擎以库链接进宿主进程，数据就是一个文件。它是 vane 的上游地基——vane 正是在这份代码上叠加了分布式与 AI 能力。

C++ 内核 ~1400 源文件MIT 协议单文件存储 v69向量 2048

三、五条核心原理

1. 推送式向量化执行：一推到底的 DataChunk

执行单位是 DataChunk（2048 行 × N 列的 Vector 数组）。Vector 有六种物理形态（FLAT/CONSTANT/DICTIONARY/FSST/SEQUENCE/SHREDDED），算子统一经 ToUnifiedFormat 读取——常量与字典向量"零成本"适配，谓词过滤只产 selection vector 不物化。字符串 string_t 定长 16 字节：≤12 字节内联，长串存 4 字节前缀 + 指针，比较走前缀整数。

2. Pipeline + 事件 DAG：没有 MorselInfo 的 morsel 并行

查询切成多 条 Pipeline（1 source → N operators → 1 sink，阻塞算子截断）；Executor 以事件 DAG 驱动（Initialize→Run→PrepareFinish→Finish→Complete 五段），Join 构建靠"全部 Combine 后统一 PrepareFinalize"保证顺序。每线程领一个 PipelineTask，内部 PipelineExecutor 每次推 50 个 chunk 让出调度；并发拉取同一 source 即"morsel"语义，跨线程保序靠 batch index。背压是协作式的：sink BLOCKED → 任务挂起 → InterruptState 回调复活。

3. 35 遍有序优化 + DPhyp 连接序

优化器按固定顺序跑 35 遍 pass（每遍后有列绑定校验）：表达式重写 → CTE 内联/过滤推拉 → Deliminator 清理关联子查询展平产物 → JoinOrderOptimizer（DPhyp 超图 DP，1 万对上限后退化为贪心） → 统计传播（可触发 CompressedMaterialization 与空结果剪枝）。物理化阶段做算法选择：完美哈希聚合（组位宽 ≤ 阈值）、哈希/IEJoin/MergeJoin/NLJ 分派、ORDER BY+LIMIT 改写 TopN、LateMaterialization。

4. 乐观 MVCC：读永远无锁

事务拿 start_time 作读快照；写不改基表，而是压 UndoBuffer（由 BufferPool 管理，可卸盘）挂出 UpdateInfo 版本链。第二个更新同一行的人在 UpdateSegment::CheckForConflicts 处立即收到 TransactionException——没有等待、没有死锁检测。提交 = 遍历 undo 把版本号改写为 commit_id + WAL fsync；回滚 = 逆序回放 undo。

5. 单文件 + 双 Header + 签名扩展

数据文件以 magic "DUCK" 开头，两个 DatabaseHeader 交替写（meta_block 根指针），崩溃时任一时刻都有完好快照；提交只追加 WAL（fsync），WAL 超 checkpoint_wal_size 自动触发检查点：WAL 切到旁路文件 → 整库序列化（catalog 按依赖拓扑排序、行组按列段压缩）→ 新 Header 原子生效 → 截断旧 WAL。扩展是 512 字节 footer + 256 字节 RSA 签名的 .duckdb_extension，ABI 分 CPP/C_STRUCT/UNSTABLE 三档，scanner 类扩展可自动加载安装。

五、创新点

1️⃣ 零部署 OLAP

把"数据库 = 进程外服务"的假设推翻：查询、事务、存储、扩展全部库内化，配置就地取材（内存 80%、线程 = 物理核）。

2️⃣ 事件 DAG 并行运行时

不用传统调度器阻塞等待：任务可 BLOCKED 挂起、回调复活，线程永远有事可做；50 chunk 预算切片让取消与进度条都自然成立。

3️⃣ 统计驱动的物理化

统计传播不止选 join 顺序：能触发压缩物化、空结果剪枝、perfect hash 降级——优化器与存储格式深度耦合。

4️⃣ 分析库里的乐观事务

为 OLAP 定制的 MVCC：读零锁、写冲突即败、undo 走缓冲池——小事务可用，大扫描不受影响。

5️⃣ 签名扩展分发

扩展 = 带版权签名的制品：RSA 双密钥环（官方/社区）、SHA-256 分段哈希、ABI 三档兼容承诺、autoload 白名单。

6️⃣ 一切皆表函数

scan、range、read_parquet、checkpoint 语句都是 table function；文件路径替换扫描让 FROM 'x.parquet' 成立。
